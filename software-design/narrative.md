# Software Design and Engineering 

## CS 360 Weight Tracker Application

### Enhancement Narrative

Artifact Description

The artifact I selected for my software design and engineering enhancement is a Weight Tracker mobile application that I originally developed in CS 360: Mobile Architecture and Programming in October 2026. The application was created using Java and Android Studio to allow users to create accounts, establish personal weight goals, record daily weight entries, and monitor their progress over time. The application also includes functionality for managing weight history and SMS notification settings. I selected this artifact because it represents my experience developing a functional mobile application while incorporating user interface design, database management, and application functionality. It also provided an opportunity to revisit an existing project and identify improvements that could make the application more useful and informative for its users. 


Justification for Artifact Selection and Enhancement

I chose to include the Weight Tracker application in my ePortfolio because it demonstrates my ability to design, develop, and improve a software application using programming concepts and development tools. The original application incorporated several important components, including user authentication, persistent data storage, weight tracking, and interactive user interface elements. 
For my software engineering enhancement, I focused on improving how the application communicates progress toward a user’s weight goal. Previously, the application displayed the user’s goal, latest recorded weight, and weight history. Although this information was available, the user had to interpret the values to determine how close they were to reaching their goal. 
To improve this functionality, I added progress summary logic to the application’s MainActivity.java file and introduced a corresponding TextView component in the activity_history.xml layout. The enhancement was designed to calculate the difference between the user’s current weight and their established goal while accounting for whether the user intended to gain or lose weight. 
The updated logic also includes conditions for situations in which a goal has not been established, no weight entries are available, or the user has reached their goal. These changes were intended to make the application more informative and provide clearer feedback without requiring users to calculate their progress manually. This enhancement demonstrates my understanding of conditional logic, user interface development, and modifying existing software to improve the user experience. 


Course Outcomes and Progress

My original enhancement plan included improving the application’s software design through additional separation of responsibilities and a more informative display. During this milestone, I concentrated on implementing the progress summary functionality rather than completing every architectural improvement originally proposed. The enhancement demonstrates progress toward the Computer Science program outcome involving the design and evaluation of computing solutions that address specific problems using appropriate computer science practices. By introducing calculations and conditional statements to evaluate a user’s progress, I applied programming principles to improve the usefulness of an existing application. 
The project also demonstrates progress toward the outcome involving the use of computing tools, and software development techniques. I worked with Java source code, Android XML layouts, Visual Studio Code, and Gradle to modify and build the enhanced project. 
Although I did not complete the planned service and repository restructuring during this milestone, the progress summary enhancement provides a foundation for future improvements. Additional development could separate the progress calculations from the activity class to improve maintainability and support further testing. 


Reflection on the Enhancement Process

Working on this enhancement helped me to better understand the challenges involved in modifying an existing software application. While developing a new application requires planning and implementation, enhancing an existing project also requires understanding how its current components interact and ensuring that modifications do not interfere with established functionality.One of the challenges I encountered was working with the enhanced project in Android Studio. Although the original application was functional in the Android emulator, I experienced difficulties opening the separate enhanced project. To avoid unintentionally modifying the original application, I maintained a separate copy of the project and continued making the enhancement changes in Visual Studio Code. I was able to add the progress summary logic and update the corresponding XML layout. I also successfully completed a Gradle build of the enhanced project.However, I was unable to complete runtime testing of the enhanced version in the Android emulator during this milestone. This experience reinforced the importance of distinguishing between successful compilation and verifying that an application functions correctly when executed.Another important lesson involved recognizing the value of incremental improvements. Although my original plan included broader architectural changes, focusing on the progress summary allowed me to implement a specific enhancement while continuing to develop my understanding of the existing code. Overall, this milestone strengthened my confidence in reviewing existing code, identifying opportunities for improvement, and implementing changes using software development tools. It also helped me recognize areas where I can continue improving, particularly in project configuration, testing, and software architecture. These experiences will be valuable as I continue developing my technical skills and preparing to enter the computer science field.
